# 根文件系统构建(7.27)

根文件系统 rootfs 是 Linux 启动后挂载到 / 的用户空间目录结构。内核启动完成后，会尝试执行 /sbin/init、/etc/init、/bin/init、/bin/sh 等程序。如果 rootfs 中没有可执行的 init，内核会 panic。
/bin：普通用户命令，如 sh、ls、cp、mount
/sbin：系统管理命令，如 init、ifconfig、mdev
/lib：动态链接库，如 libc.so、ld-linux-armhf.so.3
/etc：系统配置文件，如 inittab、fstab、init.d/rcS
/dev：设备节点，也可以由 devtmpfs/mdev 动态生成
/proc：proc 虚拟文件系统挂载点
/sys：sysfs 虚拟文件系统挂载点
/tmp：临时目录
/mnt：挂载目录
/usr：用户程序和库

BusyBox 提供嵌入式 Linux 常用命令和 init 程序。构建 rootfs 时，通常先交叉编译 BusyBox，再 make install 到根文件系统目录，生成 bin、sbin、usr 等基础命令。

/etc/inittab：指定系统启动后执行哪些初始化动作
/etc/init.d/rcS：系统启动脚本，常用于挂载 proc、sysfs、devtmpfs，配置网络等
