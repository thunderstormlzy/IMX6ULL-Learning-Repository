# 新字符设备驱动开发（8.5）

cat /proc/devices查看所有设备号
/devices/XXX查看是否创造了XXX设备文件节点
加入了动态设备号注册和静态设备号注册两种模式，若无给定主设备号，则进行动态设备号注册，反之则是静态设备号注册
同时把设备节点文件的创建放入了内核编辑里
cdev_init函数初始化cdev，将操作表和cdev相连接；cdev_add() 将 cdev 和已经分配好的设备号注册到内核中，因此VFS可以通过设备号来访问操作表
medv会根据系统中硬件设备状态来创建或者删除设备文件，也就是在rcS中包含的
echo /sbin/mdev > /proc/sys/kernel/hotplug命令，因此为了创建所需的设备文件节点，需要创建对应的class类，
newchrled.class = class_create(THIS_MODULE, NAME);
THIS_MODULE表明是当前设备，NAME表明是该模块名称，防止错误或者过度创建，
创建完对应的class类后，创建对应的设备文件节点
device = device_create(struct class *class,struct device *parent,dev_t devt,void *drvdata,const char *fmt);
参数 class 就是设备要创建哪个类下面；参数 parent 是父设备，一般为 NULL，也就是没有父设备；参数 devt 是设备号；参数 drvdata 是设备可能会使用的一些数据，一般为 NULL；参数 fmt 是设备名字，如果设置 fmt=xxx 的话，就会生成/dev/xxx 这个设备文件。返回值就是创建好的设备。
同时，创建完成后，卸载模块时需要把创建的内容释放，根据释放顺序为先释放设备文件节点，然后是class类，接着是cdev，最后是设备号
    device_destroy(newchrled.class, newchrled.devid);
   class_destroy(newchrled.class);
    cdev_del(&newchrled.cdev);
    unregister_chrdev_region(newchrled.devid, NEWCHRDEV_CNT);
