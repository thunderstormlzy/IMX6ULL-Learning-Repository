# 字符设备驱动开发（8.3）

加载模块→注册字符设备→创建设备节点→测试驱动运行情况→注销字符设备→卸载模块
模块一般放在 rootfs/lib/modules/4.1.15+，其中 4.1.15+ 是当前 Linux 内核版本号（Linux kernel），实际路径要和 uname -r 输出一致。
module_init 注册模块加载入口函数，insmod 时执行；module_exit 注册模块卸载出口函数，rmmod 时执行。
注册字符设备一般需要三个参数register_chrdev(unsigned int major, const char *name,
const struct file_operations *fops)也就是主设备号，设备名以及操作函数集
其中主设备号当register_chrdev 中 major 传入 0 时，内核会自动分配一个未占用的主设备号；传入指定值时，就是静态指定主设备号。
其中file_operations是驱动提供给VFS调用的操作函数表（包含open，read，write，release），里面的各个操作函数都对应了相关的内核操作函数（例如.open = chrdevbase_open）
补充：MODULE_LICENSE("GPL") 用来声明模块许可证，不写可能会出现内核警告。
